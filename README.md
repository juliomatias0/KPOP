# Além do Espelho — Pressão Estética no K-pop

Site educativo responsivo em HTML, CSS e JavaScript puro.

## Estrutura
- `index.html`
- `assets/styles.css`
- `assets/script.js`

## Como abrir
1. Extraia a pasta.
2. Dê dois cliques em `index.html`.
3. Para editar, abra a pasta no VS Code.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html` e a pasta `assets`.
3. Em **Settings → Pages**, selecione a branch `main` e a pasta `/root`.
4. Salve e aguarde a URL pública aparecer.

## Recursos
- Layout adaptado para celular, tablet e computador.
- Tema claro/escuro.
- Modo preto e branco (P&B).
- Preferências salvas no navegador.
- Menu mobile.
- Animações de entrada.
- Indicador de progresso de leitura.
- Seção de fontes acadêmicas.

## Personalização rápida
Procure por:
- `ALÉM DO ESPELHO` para trocar o nome do projeto.
- `© 2026 • Projeto educativo` para inserir nome do autor.
- `--accent` no `assets/styles.css` para trocar a cor principal.
